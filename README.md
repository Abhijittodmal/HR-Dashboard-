# 👥 HR Analytics Dashboard

## 📊 Project Overview

This project is an interactive HR Analytics Dashboard developed using
Microsoft Power BI.

The dashboard provides insights into employee demographics,
workforce composition, salary distribution, employee performance,
and other HR-related metrics.

It helps HR teams and management understand workforce trends
and make data-driven decisions.

---

## 🎯 Objectives

- Analyze overall employee headcount.
- Understand employee demographics.
- Analyze salary distribution.
- Track employee performance.
- Analyze employee attrition.
- Identify department-wise workforce trends.
- Analyze employee tenure and experience.
- Provide interactive HR insights using Power BI.

---

## 🔄 Data Processing

The data was cleaned and transformed using Power Query.

The following steps were performed:

1. Imported the dataset.
2. Removed duplicate records.
3. Handled missing values.
4. Corrected data types.
5. Cleaned employee information.
6. Created calculated columns where required.
7. Created DAX measures.
8. Built interactive visualizations.

---

## 🧮 DAX

DAX measures were created for important HR metrics such as:

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Salary
- Average Age
- Average Experience

## 💡 Key Insights

The dashboard helps identify:

- Departments with the highest number of employees.
